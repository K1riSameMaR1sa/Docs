# 网页制作入门

本文面向第一次接触网页开发的读者。你将从一个最简单的网页开始，逐步完成一个个人博客主页和一个登录页面。示例只使用 HTML、CSS 和原生 JavaScript，不需要安装框架或后端服务。

## 准备工作

### 需要的工具

- 一款代码编辑器，例如 Visual Studio Code、Notepad++ 或系统自带文本编辑器。
- 一款现代浏览器，例如 Chrome、Edge 或 Firefox。
- 不需要安装 Node.js、数据库或其他依赖。

### 建议的文件结构

每个示例都放在自己的文件夹中，便于理解和运行：

```text
web-basics/
├── basic/
│   └── index.html
├── blog/
│   ├── index.html
│   ├── style.css
│   └── script.js
└── login/
    ├── index.html
    ├── style.css
    └── script.js
```

创建对应文件后，把下面的代码分别复制进去。文件名和扩展名需要保持一致。

## 最简单的网页模板

### 文件：`basic/index.html`

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>我的第一个网页</title>
    <style>
      body {
        margin: 0;
        font-family: system-ui, -apple-system, "Segoe UI", sans-serif;
        line-height: 1.6;
        color: #1f2937;
        background: #f3f4f6;
      }

      main {
        max-width: 680px;
        margin: 10vh auto;
        padding: 2rem;
        background: white;
        border-radius: 12px;
        box-shadow: 0 8px 24px rgb(0 0 0 / 8%);
      }

      h1 {
        margin-top: 0;
        color: #2563eb;
      }

      button {
        padding: 0.6rem 1rem;
        border: 0;
        border-radius: 6px;
        color: white;
        background: #2563eb;
        cursor: pointer;
      }
    </style>
  </head>
  <body>
    <main>
      <h1>你好，网页世界！</h1>
      <p>这是一个由 HTML 结构和 CSS 样式组成的网页。</p>
      <button id="helloButton" type="button">点击我</button>
      <p id="message" aria-live="polite"></p>
    </main>

    <script>
      const helloButton = document.querySelector("#helloButton");
      const message = document.querySelector("#message");

      helloButton.addEventListener("click", () => {
        message.textContent = "你刚刚运行了 JavaScript！";
      });
    </script>
  </body>
</html>
```

### 代码说明

- `<!doctype html>` 告诉浏览器这是 HTML5 文档。
- `<head>` 中放页面标题、字符集和适配移动端的设置。
- `<body>` 中放用户能看到的内容。
- `<style>` 负责外观；`<script>` 负责交互。
- `querySelector` 找到按钮和提示文字，`addEventListener` 监听点击事件。

### 文件：`blog/script.js`

```javascript
const themeButton = document.querySelector("#themeButton");

themeButton.addEventListener("click", () => {
  document.body.classList.toggle("dark");
  const isDark = document.body.classList.contains("dark");
  themeButton.textContent = isDark ? "浅色主题" : "深色主题";
});
```

### 代码说明

- `<header>`、`<main>`、`<section>` 和 `<footer>` 是语义化标签，能帮助浏览器和辅助工具理解页面结构。
- `style.css` 使用 Grid 排列文章卡片，并用媒体查询适配手机屏幕。
- `script.js` 给按钮绑定点击事件，通过切换 `dark` class 改变主题。
- 示例中的文章链接使用 `#` 占位；实际使用时可以改成文章文件或真实地址。

### 文件：`login/script.js`

```javascript
const loginForm = document.querySelector("#loginForm");
const email = document.querySelector("#email");
const password = document.querySelector("#password");
const emailError = document.querySelector("#emailError");
const passwordError = document.querySelector("#passwordError");
const successMessage = document.querySelector("#successMessage");

loginForm.addEventListener("submit", (event) => {
  event.preventDefault();
  emailError.textContent = "";
  passwordError.textContent = "";
  successMessage.textContent = "";

  let isValid = true;

  if (!email.validity.valid) {
    emailError.textContent = "请输入有效的邮箱地址。";
    isValid = false;
  }

  if (password.value.length < 6) {
    passwordError.textContent = "密码至少需要 6 个字符。";
    isValid = false;
  }

  if (isValid) {
    successMessage.textContent = "表单验证通过（这里只是演示，没有实际登录）。";
  }
});
```

### 代码说明与安全提醒

- `label` 的 `for` 属性和输入框的 `id` 对应，便于点击标签和使用屏幕阅读器。
- `type="email"`、`required` 和 `minlength` 提供了浏览器原生约束；JavaScript 再显示更明确的中文提示。
- `event.preventDefault()` 阻止表单跳转，方便演示前端校验。
- 真实项目必须通过 HTTPS 将表单提交到后端，并在服务器端再次校验。不要把密码保存到前端代码、日志或 `localStorage` 中。此示例不包含真实认证功能。

## 运行方法

### 直接打开文件

在文件管理器中双击以下任意文件即可预览：

- `basic/index.html`
- `blog/index.html`
- `login/index.html`

### 使用本地服务器（推荐）

本地服务器更接近真实网站的运行方式。在 `web-basics` 文件夹中打开终端，任选一种已安装的工具：

```bash
# Python 3
python -m http.server 8000
```

然后在浏览器访问：

- <http://localhost:8000/basic/>
- <http://localhost:8000/blog/>
- <http://localhost:8000/login/>

关闭终端中的服务器即可停止运行。修改 CSS 或 JavaScript 后刷新浏览器，就能看到变化。

## 常见问题

### 页面没有样式怎么办？

确认 `index.html` 和 `style.css` 在同一个示例文件夹中，并且 HTML 中写的是 `href="style.css"`，不要多写或少写文件夹名称。

### JavaScript 没有反应怎么办？

打开浏览器开发者工具（通常按 `F12`），查看 Console 是否有错误。示例使用了 `defer`，因此脚本会在 HTML 解析后执行；同时确认 `script.js` 的文件名和路径正确。

### 中文显示乱码怎么办？

确认 HTML 文件保存为 UTF-8，并保留 `<meta charset="utf-8">`。
