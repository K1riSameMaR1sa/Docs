# Docs

这是一个用于整理和分享实用 Markdown 文档的仓库。内容以清晰、易读、可直接实践为目标，适合学习记录、操作指南、知识总结和经验备忘。

## 文档目录

| 文档 | 简介 |
| --- | --- |
| [网页制作入门](./网页制作入门.md) | 面向初学者的网页制作指南，包含 HTML、CSS 和 JavaScript 的基础示例 |

## 使用方法

你可以直接在 GitHub 上阅读 Markdown 文档，也可以将仓库克隆到本地：

```bash
git clone https://github.com/K1riSameMaR1sa/Docs.git
cd Docs
```

文档中的代码示例可以复制到本地文件中运行。建议优先阅读文档中的“准备工作”“文件结构”和“运行方法”部分，以便快速复现示例。

## 仓库结构

```text
Docs/

└── 网页制作入门.md
```

随着文档增加，可以按照主题或用途建立目录，例如：

```text
Docs/
├── 前端/
├── Python/
├── Linux/
└── Git/
```

## 添加新文档

欢迎补充实用文档。添加内容时建议遵循以下原则：

1. 使用清晰、准确的标题，并在开头说明文档适用人群和目标。
2. 为较长的文档添加目录，合理使用标题层级。
3. 示例代码应尽量完整、可运行，并说明文件结构和运行方法。
4. 对命令、配置和代码中的重要参数给出简短解释。
5. 不要提交密码、API Token、私钥或其他敏感信息。
6. 新增文档后，同时在本 README 的“文档目录”中补充链接和简介。

## 提交变更

提交前请检查 Markdown 标题、链接、代码围栏和示例内容是否完整：

```bash
git status
git diff --check
```

提交信息应简洁说明本次变更，例如：

```bash
git add README.md
git commit -m "完善文档仓库说明"
git push
```
